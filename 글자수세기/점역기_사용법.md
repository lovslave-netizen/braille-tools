## 마커 전체 목록 (입력 텍스트에 이렇게 적으면 됨)

| 적는 법 | 변환 결과 | 비고 |
|---|---|---|
| `@@p10` | `\|lea #aj` | 페이지 번호. 숫자는 점자식 인코딩(1→a...9→i, 0→j, `#` 전치) |
| `@@r내용` | `\|rfs 내용점역\|rfe` | 꼬리말. **엔터 치기 전까지**가 내용 |
| `@@s` | `\|svpnp4:0:3:0` | 홀수페이지 표시 (고정값) |
| `@@n` | `\|svpnp4:0:0:0` | 페이지표시 숨기기(모든 페이지) — `svrfp1`은 이걸로 대체해서 안 씀 |
| `@@v1` | `\|pv1` | 시작할 점자페이지. 숫자는 **리터럴 그대로**(인코딩 안 함) |
| `@@f10`↵`안녕` | `\|fr;p~".`↵`#aj`↵`안녕점역` | 점자페이지표시줄. 숫자는 인코딩, 다음 줄 있으면 그 내용도 점역해서 이어붙임 |
| `_한글_` | `,-...-'` | 밑줄. 한글은 단어수 상관없이 통짜 open/close |
| `__한글__` | `;-...-2` | 굵게. 한글은 통짜 open/close |
| `_word_` (1~2단어) | `_1word _1word` | 밑줄, 영어. 단어마다 `_1` |
| `_word word word_` (3+단어) | `_7word word word_'` | 밑줄, 영어. 열고(`_7`)/닫고(`_'`) |
| `__word__` (1~2단어) | `^1word ^1word` | 굵게, 영어. 위와 동일 구조 |
| `__word word word__` (3+단어) | `^7word word word^'` | 굵게, 영어. 위와 동일 구조 |
| HWP 실제 굵게/밑줄 서식 (RTF 경유시) | 위 언더바 규칙과 동일하게 처리 | `rtf_to_braille.py` 사용시에만 해당 |
| HWP 실제 페이지나누기 (RTF 경유시) | `\|pg ` | `rtf_to_braille.py` 사용시에만 해당 |
| 원문의 실제 엔터(줄바꿈) | `\|< ` | **단, `@@p숫자` 바로 다음 줄은 예외 — 자동으로 스페이스로 합쳐짐** (아래 참고) |
| `^45,2^word` 등 옛날 캐럿코드 | `__word__`/`_word_`로 자동 변환 후 처리 | 점자랑 GUI가 예전에 쓰던 방식, 자동 인식돼서 안전하게 처리됨 |
| 그 외 `^숫자,숫자^` 형태 코드 | 그대로 통과 (점역 안 함) | 빈칸 표시(`^46,36^` 등) 같은 진짜 리터럴 코드 |

**빼기로 결정한 것**: `svrfp1`(홀수 푸터만 숨김 — `@@n`으로 통합), `rfd`(안 씀). `[pg][pv3]`도 이미 `pg`+`@@v`로 커버됨.

## 자동 전처리 규칙 (사람이 신경 안 써도 됨)

1. **`@@p10` 바로 다음 줄에 본문이 이어지면** 자동으로 그 사이 줄바꿈을 스페이스로 합침
   (`direct_translate.py`의 `remove_linebreak_after_page`). 안 그러면 `|lea #aj|< 본문...`처럼
   `|<`가 페이지코드 뒤에 끼어들어서 지저분해짐. **`@@p` 줄 바로 다음 줄부터 본문 이어써도
   자동으로 처리되니 신경 안 써도 됨.**
2. **`@@r` 앞에 줄바꿈이 없으면** 자동으로 넣어줌 (`insert_linebreak_before_footer`).
3. **스페이스 2개 이상 연속(들여쓰기 등)은 `|'`로 자동 변환.** 단어 사이 스페이스 1개는
   안 건드림. (덕스베리가 연속 스페이스 2개 이상을 못 받아서 나온 규칙, 2026-08-27 확인)
4. **`.bru` 파일 첫 줄엔 항상 `\|no-par \|spacing \|compress `가 자동으로 붙음.**

## 역점역(`역점역기.exe`) 관련 중요 사실

- 입력은 **반드시 소문자로 바꿔서** DLL에 넣어야 정상 작동함 (대문자 그대로 넣으면
  완전히 다른 한글 자모 조합으로 깨짐). `역점역기.py`가 자동으로 처리하니 신경 안 써도 됨.
- 빈 줄을 그대로 역점역 함수에 넣으면 DLL이 쓰레기값을 뱉음 → 빈 줄은 자동으로 건너뜀.
- **자동 교정 사전**(`REVERSE_CORRECTIONS`, `역점역기.py` 안에 있음) — 역점역 결과에
  항상 깨져서 나오는 고정 패턴을 실제 의미로 자동 교정:
  - `ㅍㅍㅍ` → `...`
  - `ㅅㅎ` → `)`
  - `닾` → `다.`
  새로운 깨짐 패턴 발견하면 이 사전에 계속 추가하면 됨.
- 한 번에 여러 줄(개행 포함)을 통째로 넣으면 줄바꿈이 사라지므로, 줄 단위로 쪼개서
  처리 후 다시 이어붙이는 방식으로 되어 있음.

## 글자수세기 (2026-10-13 추가)

`E:\파이썬\점역tools\dist\글자수세기_점역내장.exe` (소스 `글자수세기.py`, 역점역기.py를 import). 점사랑7 없는 PC에서도 돌아감(DLL 내장, 약 23MB).

BRF(점자) 텍스트를 역점역해서 **글자 수**를 센다. 마침표 등 문장부호도 1글자(`안녕하세요.`=6). 공백 제외/포함 둘 다 표시.

- **입력**: 위 칸에 붙여넣기(일부만 OK) 또는 [파일 열기].
- **기본 언어**: 자동판별(기본) / 한글 / 영어. BRF 중간만 복사하면 영어표시(`,` 등)가 없어 한글 모드에선 영어가 깨짐 -> 영어 모드(DLL languageMode=1) 사용. 자동판별은 줄마다 영어로 읽어 말이 되면 영어, 아니면 한글(어림짐작이라 아주 짧은 줄은 한글로 침).
- **읽은 시간**: `2`(분) / `1:33` / `1분33초` / `93초` -> 1분당 글자 수 표시.
- **쪽 선택**(파일 열었을 때): `5` 또는 `3-5`, 비우면 전체. "점자 쪽번호"(쪽 맨 아래 줄 끝 `#A`, `#AAE` = 1, 115. a~j=1~9,0) / "파일 순서". 쪽은 폼피드(\f)로 나누고, 폼피드 없으면 "쪽당 줄수"(기본 26)로 나눔. 번호는 앞면에만 있어서 뒷면은 앞쪽+1로 계산. 같은 번호가 중복(속표지/재시작)이면 뒤의 것 사용. 쪽번호 없는 파일은 자동으로 파일 순서. 글자 수에서 쪽번호(`#...`)는 제외.
- 실제 BRF(Z:\ 및 불편한 편의점3-1)로 쪽 구조 검증함. 폼피드 없는 실제 파일은 못 찾아서 줄수 방식은 미검증.

- **ㅍ받침 보정**(역점역기/글자수세기 공통, `역점역기.py`의 `_pieup_to_period`): ㅍ받침과 마침표는 점형이 같아서 `몰라요.`가 `몰라욮`으로 읽힘 -> 진짜 ㅍ받침 글자(앞 옆 숲 잎 깊 높 덮 갚 짚 엎 읊 릎 겊 늪 섶)는 **뒤에 글자가 이어질 때만**(공백/줄바꿈 건너뜀) 그대로 두고, 뒤에 기호뿐이거나 끝이면 `받침 뺀 글자 + .`(앞 -> `아.`), 목록에 없는 글자는 항상 `받침 뺀 글자 + .`로 자동 교정. 예외 글자가 더 있으면 `_REAL_PIEUP`에 추가.
